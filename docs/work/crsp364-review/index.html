RELEASE-71: Settings tabs, update progress, bars and dots

Terminal Green, dark. Every screenshot is at actual size (1300 px or 393 px wide), full page, stacked. No thumbnails. The page scrolls sideways at 1300 px; that is the real size.

Short study

  • CRSP365 Settings tabs. Seven tabs: Access, Repositories, Themes (Appearance), Networking (Notification channels, Network, Metrics), Updates, Data, Audit log. /settings/console goes to Themes; /settings/console#notifications|#network|#metrics and the old /settings/network, /settings/metrics go to Networking. Each tab keeps its own Save bar. The Help line for Settings now says "Access, repositories, themes, networking."
  • CRSP364 update progress in one place. Before, an update showed four times (top Note with a bar, a restarting Note above the pane, the pane's Installing status, the restarting Note again below). Now: the bar with the step word is only inside the Updates pane; every other page has one short top line "An update is running." with the link "See the update" (no bar, shared banner part); the Updates page has no top line; the restart is one line in the pane. A bar never sits in a Note.
  • CRSP368 last check. The Update history table is gone. The pane says "Last checked {time}, by {who} (manual)." or "Last checked {time} (automatic).", with "See all in the Audit log" (no per-action filter exists in the Audit log address, so the link opens the whole log). The API gained last_check on the update status, read from the update audit rows. Time is in the console's own date format.
  • CRSP369 bars are blocks. In the Cool Terminal themes every horizontal bar draws shared segments in Blocks and in Dots: progress bar (20 segments, primary colour; unknown total pulses), bar list (10 segments, its own note colour), level bars and meters as before. Owner rule 27 Nov: the bar list is a bar, so its CRSP362 dotted rule is removed.
  • CRSP370 dots are filled dots. Dots changes real charts only, as solid round filled dots drawn by the chart parts: column = grid of dots filling the bar's own box (CRSP374), line = line of dots, area = grid of dots, heat cell = one dot, forecast diagonal = line of dots. The CRSP362 outline over a wash is gone.
  • Known and unchanged: at 393 px the Updates pane lines are wider than the screen in places (long "Next check" line), as before this work.
