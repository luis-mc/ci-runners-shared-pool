How a job gets run

On GitHub

  • Repositorya GitHub project
  • Runone start of a workflow
  • Jobasks for a runner

In your pool

  • Queuewaits for a slot
  • Slotroom for one job
  • Runnerdoes the work
  • Machineyour computer

Questions9

What does shared mean?

Every repository you turn the pool on for uses the same machines and runners.

Open Setup > Pool setup

What are a run and a job?

A run is one start of a workflow. A job is one part of a run.

Open Pool > Jobs

What are labels?

Words on a job and on a runner. A job goes to a runner that has all of its labels.

Open Pool > Overview

What does Run elsewhere mean?

Another runner runs the job, not your pool.

Open Analytics > Run elsewhere

Why is my job waiting?

Open Why waiting on its row. Queue Analysis ranks every waiting job.

Open Pool > Queue Analysis

How big is a slot?

The pool is what is left after the load budget.

Open Setup > Size and backends

Where do I see what runs now?

The picture of running and queued jobs.

Open Pool > Live

Something is wrong

Doctor lists what needs you and checks the pool.

Open Doctor

How do I make it faster?

Suggestions are ranked by the time they save.

Open Analytics > Suggestions
