Two audits on 20 Nov 2026 showed that CI was slow for reasons no single run page shows. Jobs waited for runners for up to 4 h 53 min. Jobs ran serially when they could run in parallel. Tests slept on fixed timers, generated hundreds of cases, or had no time limit at all. crsp already sees every job it runs, so it is in the right place to find these problems for every project, and to keep finding them.

The owner's goals for this feature (20 Nov 2026):

  1. Guardrails that cannot be forgotten. Everything learned from the audits goes into the dev-standards plugins as enforcement: rules, hooks and guard scripts that run in Claude Code sessions, before a push and in CI. Memory notes are not enough.
  2. crsp audits all CI runs. It analyses each project's runs and the orchestration of all runs across projects. It recommends:
    • how to change the crsp setup to match the real demand (runners, labels, machine slots, images, caches, schedules);
    • how each project can improve its CI: run time, step order, wait time, repeated tests, tests that check nothing;
    • where each project stands against each dev-standards guardrail.
  3. Useful, not shelfware. Research best practices and similar products, test each idea against the crsp product concept, and build only what people will act on. A dashboard nobody opens is a cost in code and in the console.

This page grows as the exploration goes on over the next days. Each round adds findings, options and decisions.

The test guardrails being enforced

IDGuardrail
G1Every test runner has a per-test timeout: unit 10 s, integration 60 s, e2e 2 min. Never raise it to pass.
G2Every CI job sets timeout-minutes of 30 or less. Never raise it to pass.
G3No retries of failing tests in CI. Fix the test, or quarantine it with an issue draft.
G4No sleeps or open-ended wait loops. Use fake timers, or wait-for with a hard deadline.
G5Parametrize at most 20 cases per test unless a spec requires more. No new matrix axes without owner approval.
G6Mutation tests and property tests with many runs stay out of branch and PR CI.
G7Report the measured time of each new test.
