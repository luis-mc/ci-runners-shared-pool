Each overflow target gets an optional price per minute in US dollars (price_usd_per_minute, 0 is none) that the monthly budget counts: GitHub-hosted without one uses the savings rate table, AWS EC2 needs one for its budget to be enforced. The job's OS for the rate is the one GitHub reports for its runner (the repository's runner list, by runner name), the label guess only when GitHub reports none. Settings, Repositories gets the field Price per minute of <target> (USD) (R5.114, R5.115, Q24).
