# v0.1.0 owner test (CRSP2)

The owner runs this on their own Windows PC. It tests the **Edge** pre-release, which is built from the same commit that becomes v0.1.0. v0.1.0 is tagged as a stable release only after this test passes. It takes about 30 minutes. Tick each box. When a step fails, write what you saw next to it and stop there.

Before you start:

- [ ] Open the **Edge** pre-release on the repository's Releases page. Its title names commit `4a8010f`.
- [ ] Download the `crsp-windows-amd64` MSI from that page (the `crsp-windows-arm64` MSI on an ARM PC). Its name ends in the version; v0.1.0 had no version in the name.
- [ ] Pick one **private** repository from your GitHub account to test with. Public repositories stay on GitHub-hosted runners.

## 1. Install

- [ ] Double-click the MSI. Windows SmartScreen warns, because v0.1.0 is unsigned. Choose **More info**, then **Run anyway**.
- [ ] The installer asks for administrator rights once, then finishes with no other question.
- [ ] In **Services**, `crsp` (CI Runners Shared Pool) is **Running** and set to **Automatic**.
- [ ] In a new terminal, `crsp version` prints the edge version, `edge-4a8010f`. This shows the PATH entry works.
- [ ] The Start Menu has **CI Runners Shared Pool**.
- [ ] In **Windows Defender Firewall > Inbound rules**, the crsp rules for ports 8460 and 8461 apply to the **Private** profile only.
- [ ] The tray icon appears, and it comes back after you sign out of Windows and sign in again.

## 2. First run

- [ ] Choose **Open** in the tray menu, or run `crsp open`. The browser opens the console on the setup page with a setup link.
- [ ] **Connect GitHub:** choose your personal account and keep the App name. Review says "Nothing has changed yet.". GitHub creates the App and the console shows its name and permissions.
- [ ] **Sign in with GitHub** works, and you land back in the console.
- [ ] **Add the first machine:** pick Windows. Review shows the install command and how long the join code lasts. Run the command on this PC. The wizard shows the machine with its name, CPU, memory and backends.
- [ ] **Turn on the first repository:** pick only your test private repository. Done shows it turned on and its `CRSP_RUNS_ON_*` variables written.

## 3. Add a runner and run a job

- [ ] On **Runners**, add one persistent Windows runner on this PC for the test repository.
- [ ] In GitHub (repository > Settings > Actions > Runners), the runner shows **Idle**.
- [ ] Push a workflow to the test repository that uses `runs-on: ${{ fromJSON(vars.CRSP_RUNS_ON_WINDOWS) }}` (the variable holds a JSON list), or start one by hand. The job runs on this PC and goes green.
- [ ] **Overview** shows the job running, then the machine's load going back down.

## 4. Tray menu

- [ ] The header of the menu shows the product name, the edge version and the status (Running).
- [ ] **Open** opens the console.
- [ ] **Open log folder** opens `%ProgramData%\crsp\logs`.
- [ ] **Start at login** is ticked.
- [ ] **Open on GitHub** opens the project page.
- [ ] **Check for updates** says you are on the newest version.
- [ ] **Automatic updates** is ticked (on by default). Untick it, then tick it again. The console's update setting follows.
- [ ] **Restart** and **Update now** first show the console's Review step. Nothing happens until you confirm.

## 5. Uninstall

- [ ] In **Settings > Apps**, uninstall CI Runners Shared Pool. The **Also remove settings and data** checkbox is **unticked** by default. Leave it unticked.
- [ ] The `crsp` service, the PATH entry, the Start Menu entry, the tray autostart and the firewall rules are all gone.
- [ ] `%ProgramData%\crsp` is still there, because you kept the data.
- [ ] In GitHub, the runner from step 3 is gone. Uninstall drains it and then removes it from GitHub.

## Result

- [ ] Every box above is ticked. Tell the orchestrator "v0.1.0 test passed". v0.1.0 is then tagged as a stable release, and you are offered your private repositories for crsp, one by one, as crsp covers each one's jobs. The old runner pool stays until crsp covers every private-repo job (decision D37).
- [ ] Or something failed. Tell the orchestrator the step and what you saw. A fix ships as v0.1.1.
